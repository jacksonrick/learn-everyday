# 小学每日学习打卡系统 · 需求说明 v1.0

> 状态：待家长（产品负责人）确认 · 日期：2026-10-31
> 定位：一位家长的私用工具（单家庭、非多租户），开源项目

---

## 1. 产品定位

| 项 | 内容 |
|---|---|
| 一句话 | 孩子每天打开就能学，学完自动打卡，家长在后台看数据、管题库 |
| 核心目标 | 让"每天 15 分钟"这件事**启动成本接近 0**，并把坚持可视化 |
| 不做的事 | 不做社交、不做多租户、不做支付、不做 AI 对话答疑、不采集个人信息 |
| 目标设备 | 客户端：iPad / 手机 / 电脑浏览器（移动优先，可加到桌面）；后台：电脑浏览器 |
| 使用者 | 孩子（客户端，无需登录）+ 家长（后台，固定账号密码） |

### 1.1 设计原则（决定后续所有取舍）

1. **零登录、零等待**：打开就是今天的任务，不需要选课、不需要找入口。
2. **全自动判分**：每个环节都有可判定的答案（选择题/填空题/计算题），不依赖家长在旁边盯着。
3. **单次时长可控**：语文约 5 分钟、数学约 8 分钟、英语约 5 分钟，超时也允许暂停。
4. **奖励即时**：完成即到账、有动画，不等"周末结算"。
5. **数据可迁移**：一个 `db.sqlite` 文件 + 一个导出按钮，换电脑就是拷文件。

## 2. 核心场景（用户旅程）

**晚上 19:30，孩子自己打开 iPad**

1. 打开 → 首页显示"今日任务"，三张卡片：语文 0/2、数学 0/20、英语 0/2
2. 点"语文" → 识字 5 个字（选拼音，答错自动进错题）→ 古诗 1 首（听读 → 跟读 → 填空背诵）→ 返回首页，卡片变 ✓
3. 点"数学" → 20 道题一口气做完，键盘自动跳下一题，交卷出分数和错题
4. 点"英语" → 5 个新词 + 10 个复习词（听音选义 / 看词选义）→ 1 个句子跟读
5. 三科完成 → 全屏撒花动效 + "今日打卡成功！+40 积分，连续 12 天"
6. 顺手点"我的" → 看日历上又多一个红点，积分够换"周末多看 30 分钟动画"

**家长周末打开后台**：看本周打卡率、数学正确率曲线、错题 Top10，把下周要背的古诗加进计划。

## 4. 客户端详细需求

### 4.0 通用

- 进入即选孩子（本地记住，多孩子时首页顶部可切换，默认上次选择）。
- 首页顶部：孩子头像、年级学期、今日积分、连续打卡天数（火焰）、今日进度环。
- 全局：大字号（正文 ≥16px，题干 ≥20px）、按钮 ≥44px、点击有音效反馈（可关）、无广告无弹窗。
- 断网可继续做题（题目已下发到本地），联网后同步结果；PWA 可加到主屏。
- 退出/中断不丢进度：每答一题即**由服务端存档**（本地换设备/清缓存也不丢），回来接着做到第 N+1 题，三个科目都一样。

### 4.1 语文

#### A. 每日识字

| 环节 | 规则 |
|---|---|
| 题量 | 认读 5 字 + 组词 5 题（固定），古诗 1 首 |
| 认读卡 | 大字 + 拼音 + 部首 + 笔画数 + 结构 + 组词 2~3 个 + 例句 1 句 + 发音按钮；听读完点「下一个」即可，**不计分** |
| 组词题 | **看字选组词**（4 选 1，干扰项来自全库所有组词），答对下一题、答错显示正确答案并记入错题 |
| 计分 | 只有 5 道组词题计分；认读卡与古诗只记录完成，不进总分 |
| 范围 | 全库随机取字，不关联年级学期；认读优先取没学过的字，组词题跳过当天刚认读过的字 |

#### B. 古诗朗读背诵

古诗不再拆成「选一句 / 挖空」这类题——整首诗就在上面摆着，问其中一句没有意义。改成**听读 + 背诵录音**两步：

| 环节 | 规则 | 说明 |
|---|---|---|
| 听读 | 逐句点读；**「整首朗读」按钮放在听读标签页里** | 优先用后台为该诗上传的音频，没有则用浏览器 TTS |
| 背诵 | 切到该标签后古诗正文**立刻打码**，只留录音按钮 | 录的是孩子背完整首诗的声音 |
| 上传 | 录完可回放、可重录，确认后上传到服务端 | **不判分、不匹配答案**，但必须留下记录 + 录音 |
| 家长端 | 后台「学习数据 → 背诵录音」按孩子/日期筛选、在线试听、删除 | 录音存放在数据目录，随一起迁移 |
| 不懂 | 译文折叠展示（后台维护，可空） | 不强制阅读 |

- 每日固定 1 首，来源：全库随机 + 复习队列。
- 范围：统编教材小学 1-6 年级古诗词约 112 首，另收 13 篇文言文与蒙学选段（背诵以短句填空形式，可选开启）。
- 背过的诗进入 7/15/30 天复习队列，隔一段时间还会再遇到。

### 4.2 数学

- 每日 20 题，**严格按孩子的 年级+学期** 由规则引擎随机生成，不重复、不出现超纲（不会抽到别的年级或别的学期）。
- 难度递进：题库中配置若干"知识点组"，按权重抽题；同一知识点内随机参数区间。
- 题型：
  - 口算/笔算填空（如 `236 × 4 = ____`）
  - 竖式分步（可选，逐步填数，用于多位数乘除）
  - 比较大小、单位换算、找规律（低年级）
  - 应用题（来自人工题库，含解析）
- 交互：数字小键盘输入，回车即下一题；答完立即显示对错（可配置"交卷后统一批改"）。
- 交卷：显示得分、用时、错题清单；错题自动进错题本，提供"再练 3 道同类题"。
- 不允许跳过：「不会，跳过我」的入口在数学里已经去掉，每道题都要交一个答案。
- 计时：默认不限时但记录用时（三年级目标 20 题 ≤ 8 分钟）。
- 允许中途暂停、退出续做：答过的题即时存档，再进来**从第 N+1 题接着做**，页头写明「上次做到第 N 题」。

**各年级知识点基线（用于预置规则）**

| 年级 | 口算目标 | 代表题型 |
|---|---|---|
| 一 | 20 以内加减 | 10/20 以内加减、100 以内不进位加减 |
| 二 | 表内乘除脱口而出 | 表内乘除、百以内进退位、有余数除法 |
| 三 | 万以内加减、多位数×一位数 | 三位数×一位数、两位数÷一位数、整十整百乘除、两步混合 |
| 四 | 两位数乘除口算、凑整 | 三位数×两位数、除数是两位数、运算律简算 |
| 五 | 小数加减、同分母分数 | 小数乘除、分数加减、简易方程 |
| 六 | 分数百分数互化 | 分数乘除、百分数、比与比例 |

### 4.3 英语

| 模块 | 规则 |
|---|---|
| 单词朗读 | 每日 10 个（后台可调）认读卡：单词 + 音标 + 词性 + 中文 + 例句 + 发音；点「下一个」即完成，**不计分** |
| 音标朗读 | 每日 2 个：音标符号 + 元/辅音 + 发音要点 + 例词（可点读）+ 发音；同样不计分 |
| 词义选择 | 每日 4 道：看中文选英文 2 道 + 看英文选中文 2 道（4 选 1，计分） |
| 音标选词 | 每日 2 道：给音标找含该音的单词（计分） |
| 句子排序 | 每日 1 道：打乱的单词排成正确语序，自动判分 |
| 去重 | 当天朗读过的单词不再出词义选择题；朗读过的音标不再出音标选词题 |
| 范围 | 词库全库随机抽取，不关联年级学期；可直接导入或 AI 生成补齐 |

### 4.4 我的

1. **学习记录**：按日期分组的流水（今天做了什么、得分、用时），近 7 天正确率趋势折线。
2. **打卡日历**：月历视图，三态（三科全完成=实心、部分完成=半实心、未打卡=空心；家长补录标「补」）。宽屏右侧并列显示当月打卡天数、完成率、本月积分、本月最长连续；窄屏自动堆到日历下方。
3. **积分**：余额、今日获得、流水（来源/时间/±分数）、可兑换奖励列表（显示"还差多少"）。
4. **奖励兑换**：点击兑换 → 生成申请 → 后台审批 → 通过后扣分并提示"去找爸爸妈妈领奖励"。
5. **错题本**：按科目/知识点聚合。**只能靠重做关闭**——点「去订正」用原题快照重考，答错必须再做**，答对才算掌握**（错题本专项订正答对 1 次即关闭，每日任务里的重练题累计答对 2 次自动关闭）。没有"直接标记已掌握"的按钮。

## 5. 管理后台详细需求

### 5.1 登录

- 固定账号密码（首次启动由 `.env` 初始化，密码 bcrypt 存储），登录后 JWT 有效期 7 天。
- 无注册、无找回（改密码走后台"系统设置"，或直接改库）。

### 5.2 概览看板

今日三科完成情况、本周打卡率、连续天数、正确率趋势（7/30 天）、错题学科分布、最近打卡记录。

### 5.3 孩子管理

字段：姓名、性别、出生日期（自动算年龄）、年级、学期（上/下）、头像（emoji）。
年级为内置只读数据（一年级~六年级、初一~初三），不做年级管理。
支持多孩子；年级学期**只影响数学**，变更后客户端次日按新年级学期出数学题。

### 5.4 题库管理（三科）

统一能力：列表（分页/筛选/搜索）、新增、编辑、删除。语文、英语题库不关联年级学期；数学题库按 年级+学期 归类。

> v1.3 起取消导入导出与启停用，删除即物理删除；v1.4 去掉「单元」；v1.5 去掉排序字段；v1.7 语文、英语题库去掉年级与学期。

| 科目 | 实体 | 关键字段 |
|---|---|---|
| 语文 | 识字 | 汉字、拼音、部首、笔画、结构、组词（2-3）、例句、是否重点 |
| 语文 | 古诗 | 标题、作者、朝代、正文（按句分行）、逐句拼音、译文、注释、赏析、类型（诗/词/文言文/蒙学）、音频 URL |
| 数学 | 出题规则 | 知识点名、generator（如 `mul_3x1`）、参数区间、是否允许进位、权重、启用 |
| 数学 | 应用题 | 题干、答案、单位、解析步骤、知识点、难度、年级学期 |
| 英语 | 单词 | 单词、音标、词性、中文释义、例句+译文、音频 URL |
| 英语 | 音标 | 音标符号、类型（元音/辅音）、例词 3 个、口型提示、音频 URL |
| 英语 | 句子 | 英文、译文、重点词 |

**每日任务配置**：每科每日题量（新/复习）、诗词每日首数、数学题量、是否开启某模块，均可在"系统设置"调。

### 5.5 学习记录与打卡

- 学习记录：按孩子/日期/科目筛选，可看单题作答明细，支持导出 CSV。古诗背诵在这里显示为一条「已背诵 / 未背诵」的流水，不参与对错统计。
- 背诵录音：孩子在客户端录的古诗音频，按孩子/日期筛选、在线试听、删除（连带文件）。
- 打卡记录：月视图，支持**补卡**（家长代填，标注"家长补卡"）、**作废**（清理当天全部痕迹：学习记录、当天任务、这天挣的积分、答题存档和背诵录音一起清除并重算余额，孩子端可重新做当天任务）。
- 积分流水：全部增减记录，支持手动加/减分并填写原因。

### 5.6 奖励管理

- 配置奖励：名称、消耗积分、图标、库存（可无限）、适用孩子。
- 兑换审批：待审批列表（通过/驳回），通过后扣分、写流水。

### 5.7 设置

每日题量、判分严格度（是否即时显示对错）、积分规则参数、连续打卡里程碑、语音开关、数据备份（一键下载 db.sqlite）、初始化演示数据、清空学习记录。

## 6. 打卡与积分规则（需确认的核心规则）

### 6.1 打卡判定

| 项 | 规则 |
|---|---|
| 单科完成 | 语文：识字+古诗都完成；数学：20 题全部作答；英语：单词+句子完成 |
| 每日打卡 | **三科全部完成** → 打卡成功（1 天） |
| 部分完成 | 记录为"部分完成"，不计打卡，不给打卡奖励 |
| 补卡 | 仅家长在后台可补；补卡日不计入连续天数（避免破坏激励真实性），但计入总天数 |

### 6.2 积分

| 行为 | 积分 |
|---|---|
| 单科完成（正确率 ≥60%） | +10 |
| 单科优秀（正确率 ≥90%） | 额外 +5 |
| 三科全完成（打卡） | +20 |
| 连续打卡 3 / 7 / 14 / 30 / 100 天 | +10 / +30 / +60 / +150 / +500（一次性） |
| 错题重练答对 | +2/题（每日上限 20） |
| 补签卡（连续中断后补） | -50（每月限 2 次，可选功能） |
| 每日积分上限 | 100（防刷，可在后台改） |

### 6.3 遗忘曲线（识字/单词/古诗共用）

阶段 S0→S5，间隔 **1 / 2 / 4 / 7 / 15 / 30** 天；答对升级、答错降 1 级并当日重排；到期条目自动进入"今日复习"。可后台关闭，改为纯顺序推进。

## 9. 非功能需求

- **性能**：首页首屏 < 1.5s（本地）；20 题作答无卡顿；题库万级数据后台列表 < 500ms。
- **兼容**：iOS Safari 16+ / Android Chrome 100+ / Edge 100+；iPad 横竖屏；最小宽度 360px。
- **可靠性**：SQLite 每日自动备份到 `backups/`（保留 7 份）；答题过程本地草稿防丢。
- **隐私**：不采集姓名以外信息、不接第三方统计、录音不上传。
- **可维护**：题库导入导出齐全，家长可自行增删；代码带 AGENTS.md 便于 AI 协作。
- **离线**：PWA 缓存静态资源与当日任务，断网可完成当天任务，联网自动补传。

## 10. 分期计划

| 阶段 | 内容 | 交付 |
|---|---|---|
