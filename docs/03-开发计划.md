## 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 教材识字表按册数据不全 | 识字与课堂进度不同步 | 字库全量入库 + 后台 CSV 导入教材表覆盖；文档说明 |
| 浏览器 TTS 音色一般/离线不可用 | 古诗朗读体验降级 | 支持后台为单条上传音频；PWA 缓存音频 |
| 三年级三位数×一位数口算偏难 | 孩子挫败 | 规则默认允许进位但控制区间；正确率低于 60% 时次日降难度 |
| SQLite 并发写 | 多设备同时提交偶发锁 | WAL + 短事务 + 前端串行提交 |
| 数据丢失 | 心血白费 | 每日自动备份 + 一键下载 |

## 约定

- 每个里程碑完成即 `git commit`，并在 `AGENTS.md` 记录进展。
- 未通过验收不进下一阶段。
